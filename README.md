# Inventory Reservation System

A modern Inventory Reservation System built using Next.js and TypeScript that allows users to reserve products in real-time with a checkout countdown timer and stock management workflow.

# Project Overview

The Inventory Reservation System enables users to:

- View available products
- Check warehouse stock
- Reserve products
- Access a checkout reservation page
- Confirm or cancel reservations
- Experience a countdown timer during checkout

The application simulates a real-world inventory reservation workflow used in e-commerce and warehouse systems.

# Application Workflow

1. User opens homepage
2. Product cards are displayed
3. User clicks "Reserve Product"
4. Checkout page opens
5. Reservation timer starts
6. User confirms or cancels reservation
